# FileSharing Web

FileSharing Web 使用 React、TypeScript 和 Primer React。左上角菜单用于选设备、管理当前设备的共享和切换语言。右上角 Access 开关通过 Passkey 管理会话。访问文件和控制终端都需要授权设备的当前连接。

## 本机运行

需要 Node.js 20.19+ 或 22.12+、npm 和 [本机 Demo 的依赖](../docs/local-demo.md)。

```bash
npm --prefix web ci
FILESHARING_DEMO_WEB_ORIGIN=http://localhost:5173 scripts/demo-server.sh start
npm --prefix web run dev
```

访问 [http://localhost:5173](http://localhost:5173)。如果 Demo 服务器已在 `http://localhost:8847` 模式运行，先结束正在使用的测试操作，再用 `scripts/demo-server.sh stop` 停止该实例，然后按上方命令启动。Mac Agent 仍连接 `http://localhost:8847`。原 Demo 页面在 Web 开发服务器的 `/demo`。

首次解锁时，从 `.local/demo/.env` 取得部署密钥，通过浏览器注册 Passkey。之后可直接使用已注册的 Passkey。选择在线设备并授权当前连接，即可浏览已共享目录。

## 文件访问

- Downloads、Documents 和 Desktop 显示 Agent 回报的 macOS 权限状态。进入需要授权的目录后可发起请求，并在目标 Mac 响应系统提示。
- 默认 HOME 共享中的普通目录可按本机权限新建、上传、改名和移动。Downloads、Documents 和 Desktop 使用 macOS 的目录授权。`~/Library` 和 `~/Applications` 按只读处理，其他共享根的授权在「共享文件夹」管理。
- 左上角菜单的「外观」可选择标准或高对比度，两种设置均自动跟随系统的亮色或暗色。桌面目录树可以拖动分隔线或用方向键调整宽度，浏览器会记住宽度。
- 文件列表支持显示隐藏项、列设置、服务端排序和滚动到底自动加载下一页。分页期间标题栏、导航和路径栏固定。目录概要显示已完整加载的当前层级可见项目合计。需要递归统计时，在「查看信息」选择「统计文件夹」。
- 单击整行选中，双击打开。⌘ 单击切换单项，Shift 单击或配合方向键选择连续范围，按住鼠标或触控板拖动可框选。⌘A 选择当前目录中所有符合隐藏项设置的项目，包括后续页。一次下载最多包含 100 个所选项目。
- 右键单击文件或文件夹，或聚焦该行后按 Shift+F10，打开与行尾按钮相同的操作菜单。可写项目提供重命名和移动，可写文件夹的菜单还可直接在该文件夹中新建目录或上传。
- 按 ⌘⇧G 或从左上角选择「前往」，输入相对于当前文件夹的路径、`~/` 开头的用户目录路径，或已共享目录内的绝对路径。方向键选择建议，Tab 补全，Enter 跳转到文件或文件夹。
- 图片先显示缩略图，可在预览区选择「加载原图」。浏览器无法显示原图时继续展示缩略图。另支持文件信息、PDF 首页预览、直接下载和 ZIP 下载。
- 重命名、新建文件夹和上传会就地提示无效名称、保留名称、过长和重名。移动会检查源和目标的权限，检查目标是否为原目录或源文件夹的子目录，并提示同名冲突或不同卷。
- 上传支持 64 GiB 以内的单个文件，显示传输进度，保存前可以取消。网络临时失败会重试当前分块。失败后保留选中的文件和目标名称。替换同名文件需明确确认，期间目标版本发生变化时需要再次核对。
- 改名、移动、移到废纸篓和确认后永久删除均由服务端检查条目版本及权限。

## 终端

- 点击顶栏命令栏打开 Quick Run。输入 `~/`、`./` 或 `/` 开头的路径可补全并打开已共享的文件或文件夹。输入命令可在授权的设备上运行，并查看即时输出。命令以路径开头时可用 `>` 指定命令模式。
- 一个设备同时保留一个活动 PTY。Quick Run 使用已有的空闲会话，或在没有活动会话时新建。可从执行结果进入终端页查看完整会话。
- 终端页侧栏按活动和历史分组，支持按首条命令搜索。选择会话可查看输出。可在独立沉浸小窗使用 Vim 等交互程序，窗口大小及按键会同步到 PTY。
- 会话、命令、输出和退出码由服务端保存。历史会话可回放、下载完整 NDJSON 记录或确认删除。关闭网页后可重新打开原会话。 [远程终端 API](../docs/api.md#远程终端会话)

## Data

从顶栏进入 [Data](http://localhost:5173/#data)。概览显示当前连接、设备状态和最近 30 分钟的采样。可通过左侧分类查看硬件、系统与 Agent、性能、电源和屏幕盖、网络与显示器、挂载卷和外接存储、应用、权限及共享授权，以及设备事件。

每个详情视图使用 File Explorer 的标题栏、可排序表头、隔行底色和独立滚动区域。分类内的不同数据集通过标题栏切换。应用清单支持搜索，滚动时逐批显示更多行，并按可见范围加载 Mac 返回的原生应用图标。

页面按所选设备接收 WebSocket 更新。推送断开时约每 15 秒读取已保存数据，设备离线时保留最后的快照。CPU、内存等采样间隔按设备策略执行，设为 0 时可以在已授权连接上选择「请求采样」。剪贴板事件显示变化时间。

## 构建

```bash
npm --prefix web run typecheck
npm --prefix web run build
```

静态产物位于 `web/dist`。提供静态文件的 HTTPS 来源应与服务端的 `FileSharing:Origin` 一致，并在同一来源转发 `/api/v1` 及其 WebSocket 请求。开发预览的后端地址可由 `FILESHARING_API_TARGET` 指定。
